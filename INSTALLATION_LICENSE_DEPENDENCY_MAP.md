**Scope:** phase-0/phase-1 read-only inventory performed before application edits. It records dependencies found in the source tree; generated/compiled public assets and third-party package source are excluded unless directly referenced by the application.

## Bootstrap Separation Decision

The commercial installer is currently responsible for normal first-run tasks: collecting database credentials, writing `.env`, importing/migrating/seeding the database, creating the first admin user and linking storage. Those tasks are not reasons to retain the commercial wizard. Laravel already supplies `.env` loading, migrations, seeders, `key:generate`, `storage:link`, configuration/cache/queue/session handling, route registration and `/up`. Before removing the wizard:

1. Remove its global request gate so standard web and API routes can load even when database tables are absent.
2. Preserve `setting()` default behavior using a guarded schema check instead of resolving `InstallationManager`.
3. Preserve dynamic application settings only when the settings schema is available, with failures safely falling back to environment/config defaults.
4. Remove automatic request-time `.env` copying and key generation; use Composer's project-install script plus standard documented Artisan commands.
5. Keep all Laravel migrations, normal application seeders, queue/scheduler, storage config, PWA installation feature, and authentication routes.
6. Do not call `CreateAdminUserSeeder` as a replacement: it truncates the admins table and creates a hard-coded default password. Fresh deployments need a controlled, operator-set initial admin account.

## Dependency Search Notes

- The principal commercial outbound calls are in `ProjectUpdateServerClient` / `EnvatoLicenseVerifier`; preserve external HTTP clients elsewhere (payment providers, Bitnob, SMS, mail, storage, merchant webhooks).
- `BackgroundTaskRunner` and `BackgroundTaskRegistry` are generic admin task execution/logging, not the updater, and remain unless a specific task references commercial update operations.
- `PROJECT_UPDATER_*` values are written by the installer to `.env.example` and consumed by updater config/service. They are not used by normal product domains.
- `APP_DEMO_*` vendor/product/sales attribution and public demo disclosure are not license enforcement; do not remove by substring matching.
- “Install” hits for PWA install, card issuance, subscriptions, plugins, notifications or third-party libraries are not server installation wizard dependencies.
- `composer.json` has no apparent package used exclusively by installer/updater; avoid dependency upgrades. `ext-zip` and `ext-dom` require post-removal use review before changing the root package requirements.
